# Vinyloop 🎵

> Custom Vinyl Background Animation Generator for Music Producers and Content Creators.

Generate high-quality custom spinning vinyl animation loops and MP4 videos directly in the browser. Customize record vinyl colors, sleeve artwork, center labels, visualizers, and export directly as seamless looping MP4 videos.

## ✨ Features

- **Vinyl Customization**: Control vinyl grooves, sheen, vinyl record color, center label, and album artwork.
- **Backgrounds & FX**: Ambient glow, particle visualizers, audio reactivity, and clean gradients.
- **Client-Side Export**: High-performance MP4 video generation using hardware-accelerated WebCodecs & `mp4-muxer`.
- **Zero Server Setup**: Fully client-side web application (HTML5, Canvas, Vanilla CSS & JS).

## 🚀 Getting Started

### Run with Python:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.

### Run with Node.js:
```bash
npx -y serve .
```
Then navigate to `http://localhost:3000`.

### Windows Quick Launch:
Double-click `run_locally.bat` to automatically launch the dev server in your browser.

## 🌐 Deploy to GitHub Pages

Because Vinyloop is a static site with no backend dependencies, it can be hosted for free on **GitHub Pages**:
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select `main` branch and `/ (root)` folder.
4. Click **Save** — your site will be live on the web in seconds!
