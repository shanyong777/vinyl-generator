# Vinyloop 🎵

> Custom Vinyl Background Animation Generator for Music Producers and Content Creators.

🌐 **Live Web App**: [https://shanyong777.github.io/vinyl-generator/](https://shanyong777.github.io/vinyl-generator/)

Generate high-quality custom spinning vinyl animation loops and MP4 videos directly in the browser. Customize record vinyl colors, sleeve artwork, center labels, visualizers, and export directly as seamless looping MP4 videos.

---

## ✨ Features

- **Direct Web & Click-to-Run**: Open in any modern web browser or click **"Install App"** to run like a desktop application.
- **PWA Ready**: Offline support and standalone window mode on Windows, macOS, Android, and iOS.
- **Vinyl Customization**: Control vinyl grooves, sheen, record color, center label, and album artwork.
- **Backgrounds & FX**: Ambient glow, particle visualizers, audio reactivity, and sleek gradients.
- **Client-Side Export**: High-performance MP4 video generation using hardware-accelerated WebCodecs & `mp4-muxer`.
- **Zero Server Setup**: 100% client-side web application (HTML5, Canvas, Vanilla CSS & JS).

---

## 🚀 How to Run

### 1. Online (Instant Click & Run)
Visit [https://shanyong777.github.io/vinyl-generator/](https://shanyong777.github.io/vinyl-generator/) in your browser.  
Click the **"Install App"** button in the header (or browser address bar) to install it directly to your desktop.

### 2. Run Locally on Windows
Double-click `run_locally.bat` to launch the local server and open your browser automatically.

### 3. Run with Python or Node
```bash
# With Python:
python -m http.server 8000

# Or with Node.js:
npx -y serve .
```
